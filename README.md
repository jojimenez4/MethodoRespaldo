# Methodo Respaldo - Sistema de Respaldo de Bases de Datos

## Descripción
Sistema automatizado para realizar respaldos de bases de datos MySQL y SQL Server.

## Instalación
1. Extraer todos los archivos del paquete ZIP
2. Configurar las variables de entorno en el archivo .env
3. Ejecutar MethodoRespaldo.exe para la interfaz gráfica

## Configuración
Editar el archivo .env con los datos de conexión:
- USER: Usuario de la base de datos
- DATABASE: Nombre de la base de datos
- EMAIL_ADDRESS: Correo para notificaciones
- BACKUP_PASSWORD: Contraseña para archivos comprimidos

## Uso
### Modo GUI
- Ejecutar MethodoRespaldo.exe
- Iniciar sesión con las credenciales
- Configurar conexión a la base de datos
- Seleccionar directorio de respaldos
- Programar respaldos automáticos
